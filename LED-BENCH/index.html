01 / Introduction

Beyond reading a single detail.

Engineering drawings are not just images of objects. They are dense, technical documents in which a small annotation can change the meaning of an entire design.

Why LED-BENCH?

Current multimodal models can recognize many visual elements, but complete engineering drawings require more: finding the right object, connecting evidence across a sheet, and deriving an exact engineering answer.

LED-BENCH provides a common, full-sheet evaluation setting across mechanical, architectural and transportation drawings. Every question is answered from the original complete visual input without question-specific crops.

05 / Reproducibility

Clear rules. Comparable results.

All models are evaluated on the same question set with a unified scoring criterion, and each question is sent in an independent request.

INPUT

Complete drawing

One original drawing sheet with one question; no question-specific region crops in the main evaluation.

ANSWER

Open-ended QA

Model responses are checked against drawing-grounded reference answers and mandatory components.

SCORING

Strict binary

Three LLM judges; omitted or incorrect essential answer components receive zero.

AGGREGATION

Domain-balanced

Accuracy is computed for each discipline, then averaged equally across Mechanical, Architecture, and Transportation.
